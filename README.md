# Description of project
Rhythm game made by Chase Graber (chase-graber), Anika Bond (anikabond), and Teresa Schneider (teresaiscoding) for AP Computer Science A.  
Inspired by most arrow-based rhythm games (Friday Night Funkin', Dance Dance Revolution, etc.)  

# How To Play
Upon entry into the level, you will be greeted by 4 arrows on your left that are controlled by a set of keys (customizable in settings, default is arrow keys).  
Pressing each key will activate the arrow, allowing it to hit the notes that fall along the track in accordance to the current song.  
Hitting the note closer to the center (and therefore closer to the time that note plays in the song) gets you a better score.  
After playing the song in full, you will get your final results before being allowed back to the main menu to choose another level.
